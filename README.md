# Ste-OS-v4.0.0-CLI-Edition-Sistema-Operativo-Bare-Metal
Ste OS v4.0.0 (CLI): sistema operativo bare-metal a 32-bit (x86) sviluppato da zero senza dipendenze esterne. Scritto al 95% in C e 5% in Assembly (NASM) con bootloader GRUB Multiboot v1. Include driver VGA testo, gestione tastiera, diagnostica hardware in tempo reale (CPU, RAM, orologio CMOS/RTC) e calcolatrice integrata.
